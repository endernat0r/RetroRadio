# RetroRadio
<img width="703" height="521" alt="Screenshot 2026-08-01 033159" src="https://github.com/user-attachments/assets/3f805063-1375-4e55-abd4-f69e8d17baaa" />

A basic radio app that has all the features a basic radio listener could need in a single neat and transparent pc app. It has features like tag search, name search and filtering.

> Built for #horizons.

## Download
1. Go to the **[Releases](../../releases)** tab on the right.
2. Download `RetroRadio.zip` and extract it into a folder.
3. Run `app.exe`.

**IMPORTANT SYSTEM REQUIREMENT:** The app uses `python-vlc` for the audio stream. You must have [VLC Media Player](https://www.videolan.org/) installed on your PC, otherwise there will be no sound.

## 💻 Development

1. Clone the repo:
```sh
git clone [https://github.com/endernat0r/RetroRadio](https://github.com/endernat0r/RetroRadio) && cd RetroRadio
```

2. Install dependencies:
```sh
pip install customtkinter pyradios python-vlc pystray pillow
```

3. Run the app:
```sh
python app.py
```
